Docs & Word × AI 스마트 문서 작성 & 번역 마스터

단순한 챗봇 복붙을 넘어선 자연어 기반 파일 처리 에이전트(Antigravity CLI)를 활용해 한글(HWP) 자료를 1초 만에 Markdown으로 변환하고, 실시간 웹 검색 기반 팩트체크 리포트 초안을 도출하며, 3대 전문 한국어 글쓰기 스킬로 교정한 뒤 직접 제작한 커스텀 Word 스킬로 최종 문서를 마감합니다.

1. 패러다임 전환: 단순 챗봇 검색 vs 파일 처리 AI 에이전트

웹 브라우저에서 대화만 주고받는 챗봇을 넘어, 내 PC의 실제 문서를 읽고 변환하며 맞춤형 스킬을 스스로 제작해 결과물을 마감하는 진정한 에이전트 워크플로를 경험합니다.

기존의 비효율적인 방식

수작업 요약과 서식 깨짐으로 지치는 리포트 작성

  • 문서 자료 변환: 한글(HWP) 문서를 복사하느라 서식이 다 깨지고 일일이 수작업으로 타이핑 변환
  • 팩트체크 & 출처: AI가 지어낸 거짓 통계·논문 출처(할루시네이션)를 검증 없이 과제에 냈다가 감점
  • 한국어 문체 교정: “생성되어진 바 있다” 등 어색한 AI 상투어와 직역 번역투가 남아 글의 품격 저하
  • 스킬 패키지 제작: 복잡한 코딩과 프롬프트를 몰라 나만의 문서 자동화 도구를 직접 만들 엄두를 못 냄
  • 최종 보고서 완성: Word 템플릿 서식이 제각각이라 인쇄 시 표가 잘리고 여백이 어그러져 마감 직전 멘붕
  • 외국어 자료 번역: 외국 논문·원서 번역 시 번역기 복붙 노가다와 표/각주 깨짐으로 시간 소모
AI 에이전트 기반 스마트 문서 작성

웹 검색 & 커스텀 스킬 자동화로 10배 빠른 고품질 리포트

  • 문서 자료 변환: 오픈소스 도구로 한글(HWP) 문서를 1초 만에 깔끔한 Markdown 파일(source_hwp.md)로 완벽 변환
  • 팩트체크 & 출처: 실시간 웹 검색(Web Search)에 기반한 인라인 출처 각주 표기 A4 1~2쪽 보고서 초안(report_draft.md) 도출
  • 한국어 문체 교정: 3대 전문 스킬(humanizer-ko · korean-prose · grammar-checker)로 상투어·번역투·맞춤법 완벽 교정
  • 스킬 패키지 제작: 샘플 Word(report_sample.docx) 분석만으로 나만의 Word 생성 스킬 패키지 직접 제작 및 등록
  • 최종 보고서 완성: 직접 등록한 스킬로 교정본을 정규 서식의 편집 가능한 MS Word(report_completed.docx)로 즉시 최종 완성
  • 외국어 자료 번역: Google Docs 클라우드 엔진으로 영문 PDF를 원클릭 한국어 사본으로 즉시 번역

2. [실습 쇼케이스] 2대 핵심 산출물 & 워크플로 미리보기

본 강의를 통해 학생이 직접 생성하고 검수하는 2대 핵심 산출물과 실무 프로세스를 미리 확인하세요.

학술 윤리 & 사실 확인(Fact-Check) 핵심 원칙
AI가 작성한 문장은 반드시 변환된 원문 자료와 대조 검증해야 합니다. 본 강의의 모든 교정 및 생성 프롬프트는 제공된 참고 문서에 명시된 사실만을 근거로 작성하도록 설계되었습니다.
Case Study 01 핵심 산출물: HWP 변환 MD & 실시간 웹 검색 기반 팩트체크 보고서 초안 Antigravity CLI · HWP 변환 도구 · Web Search

표준 프로젝트 작업 디렉터리 구조 (`ai-document-class/`)

한 번에 파일 하나, 스킬 하나를 다루는 원칙에 따라 프로젝트 폴더가 체계적으로 구성됩니다. 

ai-document-class/
├── sample_article.hwp                  # [입력] Case Study 01 변환 실습용 원본 한글(HWP) 예제
├── report_sample.docx                  # [입력] Case Study 02 Word 스킬 생성용 표준 서식 샘플
├── english_reading.pdf                 # [입력] Case Study 02 Google Docs 번역 실습용 영문 PDF
├── source_hwp.md                       # [중간 결과물] HWP 문서 Markdown 변환 산출물
├── report_draft.md                     # [중간 결과물] 실시간 웹 검색 기반 팩트 인라인 출처 초안
├── report_final.md                     # [중간 결과물] 3대 스킬 교정 완료 최종 보고서
├── report_completed.docx               # [최종 결과물] 직접 제작한 스킬로 완성한 정규 MS Word 보고서
└── .agents/
    └── skills/
        └── word-report-generator/      # [생성 스킬] 학생의 AI가 직접 제작한 커스텀 스킬
            ├── SKILL.md                # [생성 스킬] 스킬 명세서 (YAML 프론트매터 & 실행 규칙)
            ├── templates/
            │   └── report_template.docx# [생성 스킬] 샘플에서 추출한 Word 기본 양식 템플릿
            └── scripts/
                └── generate_docx.py    # [생성 스킬] MD ➔ DOCX 자동 렌더링 Python 스크립트
Step 1
자연어 CLI 환경 확인

Antigravity CLI에서 작업 폴더의 실습 파일(`sample_article.hwp` 등) 목록을 자연어로 조회하고 안전한 작업 환경을 확보합니다.

Step 2
오픈소스 스킬 검토

GitHub 저장소의 README, 라이선스, `SKILL.md`를 사전 검토한 후 승인 절차를 거쳐 스킬을 등록합니다.

Step 3
HWP ➔ MD 1초 변환

한글(HWP) 문서를 1초 만에 깔끔한 Markdown(`source_hwp.md`)으로 변환하고 원본 텍스트·문단 유지 여부를 대조합니다.

Step 4
웹 검색 기반 팩트 초안

실시간 웹 검색을 결합하여 공신력 있는 출처(URL)와 통계가 명시된 A4 1~2쪽 보고서 초안(`report_draft.md`)을 도출합니다.

Case Study 02 핵심 산출물: 교정 보고서, 나만의 Word 생성 스킬, DOCX & 영문 번역본 3대 한국어 스킬 · MS Word 스킬 패키지 · Google Docs

3대 전문 한국어 글쓰기 스킬의 역할 분담 & 교정 순서

같은 문장을 무조건 고치지 않고, 3단계에 걸쳐 수정 이유를 확인한 뒤 취사선택하여 글의 품격을 완성합니다.

스킬 이름 주요 점검 항목 실전 교정 예시
1. humanizer-ko AI 특유의 상투어, 과장, 불필요한 반복 및 어색한 이중 피동 표현 완화 “AI에 의해 생성되어진 정보” ➔ “AI가 생성한 정보”
2. korean-prose 영어 직역체, 어색한 조사 결합, 일본어 투 문장 개선 “학습 효율성의 향상을 가져오는 데 있어서” ➔ “학습 효율성을 높이는 데”
3. grammar-checker 한국어 맞춤법, 띄어쓰기, 문법 및 리포트 표준 ‘~다’체 통일 최종 문맥에 맞는 띄어쓰기 및 맞춤법 규정 완벽 검수
Step 1
3대 스킬 정밀 교정

웹 검색 초안(`report_draft.md`)의 상투어 진단 ➔ 번역투 개선 ➔ 맞춤법 검사를 거쳐 `report_final.md`를 확정합니다.

Step 2
샘플 Word 서식 분석

강사가 제공한 `report_sample.docx`의 여백, 제목 스타일, 본문 폰트, 표 규격을 AI가 자동 분석합니다.

Step 3
커스텀 스킬 직접 제작

AI가 `SKILL.md`와 Python 변환 코드를 직접 제작하여 `.agents/skills/word-report-generator/` 스킬 패키지를 등록합니다.

Step 4
직접 만든 스킬로 최종 마감

등록한 스킬을 호출해 `report_final.md`를 편집 가능한 정규 서식의 `report_completed.docx`로 최종 완성합니다.

Step 5
Docs 영문 PDF 번역

Google Drive/Docs를 활용해 영문 PDF(`english_reading.pdf`) 문서를 텍스트로 변환한 뒤 '도구 > 문서 번역'으로 한국어 사본을 생성합니다.

3. [실습 사전 준비] Windows 환경 Antigravity CLI 설치 & 실습 환경 최적화

원활한 실습 진행을 위한 필수 런타임(Node.js/Python/Git) 점검, Windows PowerShell 보안·UTF-8 인코딩 설정, Antigravity CLI(agy) 인증 및 워크스페이스 구축 가이드입니다.

1단계

사전 필수 소프트웨어 설치 (Prerequisites)

실습을 위해 학생 PC에 아래 3가지 도구가 필수적으로 설치되어 있어야 합니다. 설치 시 환경 변수(PATH) 추가 옵션을 반드시 확인하세요.

Node.js & npm
LTS 20.x 이상 권장
CLI 구동 엔진

Google Antigravity CLI(agy) 글로벌 패키지를 설치하고 실행하기 위한 자바스크립트 런타임 환경입니다.

설치 주의사항:
설치 마법사 진행 중 [Add to PATH] 체크박스가 켜져 있는지 반드시 확인합니다.
공식 배포처 nodejs.org
Python & pip
3.10 ~ 3.12 권장
문서 변환·스크립트

MarkItDown 문서 변환 및 Word(python-docx) 자동 보고서 생성 스크립트를 구동하는 핵심 인터프리터입니다.

필수 체크:
설치 첫 화면 맨 아래 [Add python.exe to PATH]를 반드시 체크해야 터미널에서 pip 호출이 가능합니다. (MS Store 버전 비권장)
공식 배포처 python.org
Git for Windows
최신 버전
스킬 클론 & 터미널

GitHub 공개 저장소에서 한국어 글쓰기 스킬을 다운로드받고 리눅스 호환 터미널(Git Bash) 환경을 제공합니다.

권장 옵션:
설치 기본값(Next)으로 진행하며, Windows Terminal 또는 기본 PowerShell과 함께 사용 가능합니다.
공식 배포처 git-scm.com
2단계

Windows 시스템 환경 3대 최적화 (PowerShell 관리자 권한)

Windows의 기본 실행 제한과 인코딩(cp949)으로 인한 한글 깨짐 및 권한 오류를 사전에 완벽히 방지합니다. PowerShell을 관리자 권한으로 실행 후 아래 명령을 복사하여 실행하세요.

[PowerShell 관리자] 시스템 환경 3대 필수 최적화 스크립트 
# 1. PowerShell 스크립트 실행 권한 허용 (외부 CLI 및 스크립트 차단 해제)
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force

# 2. 터미널 UTF-8(유니코드) 고정 (한글 파일 및 마크다운 출력 깨짐 방지)
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

# 3. 깊은 스킬 패키지 경로를 위한 긴 파일 경로 제한 해제 (선택/권장)
New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force
3단계

Antigravity CLI 글로벌 설치 & 파이썬 의존 패키지 설치

터미널에서 npm으로 Antigravity CLI를 설치하고, pip로 문서 변환(MarkItDown) 및 Word(python-docx) 라이브러리를 설치합니다.

Antigravity CLI 설치 및 계정 인증 
# Antigravity CLI 글로벌 설치
npm install -g @google/antigravity

# 버전 확인
agy --version

# CLI 실행 및 Google 계정 인증 (브라우저 로그인)
agy
문서 변환 & Word 생성 파이썬 라이브러리 
# Case Study 01 문서 변환용 Microsoft MarkItDown 라이브러리
pip install markitdown

# Case Study 02 Word 보고서 생성용 라이브러리
pip install python-docx
4단계

실습 워크스페이스 구축 & 파일 맵 확인

Antigravity CLI는 현재 실행 위치에서 .agents/skills/ 폴더를 자동으로 탐색하여 스킬을 로드합니다. 아래와 같이 실습 디렉터리를 구성하세요.

ai-document-class/ ├── .agents/ │ └── skills/ │ ├── humanizer-ko/ # Case Study 02: AI 상투어·번역투 교정 스킬 │ ├── korean-prose/ # Case Study 02: 한국어 문체·어조 다듬기 스킬 │ ├── grammar-checker/ # Case Study 02: 보고서 표준 맞춤법·문법 교정 스킬 │ └── word-report-generator/ # Case Study 02: 직접 제작할 Word 보고서 생성 스킬 │ └── SKILL.md │ ├── sample_article.hwp # [입력] Case Study 01 변환 실습용 원본 한글 파일 ├── english_reading.pdf # [입력] Case Study 02 Google Docs 번역 실습용 영문 PDF ├── report_sample.docx # [입력/참조] Case Study 02 Word 보고서 표준 서식 템플릿 ├── report_draft.md # [중간] 실시간 웹 검색 기반 보고서 초안 ├── report_final.md # [완성] 3대 스킬로 교정 완료된 최종 마크다운 └── report_completed.docx # [최종] word-report-generator 스킬이 완성한 Word 결과물
5단계

현장 트러블슈팅 빠른 체크리스트 (자주 발생하는 Windows 오류 5선)

오류 상황 / 증상 주요 원인 현장 즉시 대처 방법
'agy' 명령을 찾을 수 없음 npm global 설치 경로가 시스템 환경변수(PATH)에 미등록 터미널 재시작 후 npm config get prefix로 경로를 확인하여 환경변수 Path에 추가

[프롬프트 4] 실시간 웹 검색 기반 팩트체크 보고서 초안 생성 (P4) 웹 검색 팩트체크

[작성 조건] - 대학 및 공공 연구기관(KERIS, 학술 논문 등)의 실제 통계와 보고서 3건 이상 인용 - 허위 통계나 가짜 저자(할루시네이션)를 절대 만들어 내지 말 것 - 인용한 모든 핵심 수치와 주장에는 인라인 출처 각주(기관명, 발행년도, URL)를 반드시 표기할 것 - 서론, 본론(도입 효과 및 극복 과제 비교 표 포함), 결론의 3단 구조로 논리 정연하게 작성 - 목차를 먼저 보여 준 뒤 report_draft.md 파일로 저장할 것

3대 전문 한국어 글쓰기 스킬로 보고서 문체 완성

humanizer-ko · korean-prose · grammar-checker

humanizer-ko 상투어 진단

grammar-checker 맞춤법 검사

Case Study 02 · Step 2

샘플 Word 기반 스킬 자동 생성(DOCX) & Google Docs 영문 번역

Google Docs 바로가기 Docs 문서 번역 공식 가이드 Docs 문서 번역 가이드 python-docx · SKILL.md · Google Docs

핵심 차별화 실습: 강사가 완성된 스킬 ZIP을 제공하지 않습니다! 강사는 표준 서식 샘플인 report_sample.docx만 배포하며, 학생의 지시를 받은 AI가 샘플의 여백·스타일·폰트·표 규격을 자동 분석하여 나만의 Word 생성 스킬(`word-report-generator`)을 직접 구축합니다. 이어서 영문 PDF 문서를 Google Docs의 강력한 클라우드 엔진으로 1클릭 번역합니다.

[프롬프트 8] 샘플 Word 문서 분석 기반 스킬 자동 제작 (P8) 스킬 생성
너는 Agent Skills 제작 전문가이자 MS Word 문서 자동화 개발자야. 현재 프로젝트 루트의 report_sample.docx를 분석하여, 이 문서와 유사한 구조와 서식을 가진 편집 가능한 Word 보고서를 반복 생성하는 Agent Skill을 만들어 줘. [1. 샘플 분석] - 페이지 크기, 여백, 제목·소제목·본문 스타일, 글꼴과 크기 - 문단 간격과 정렬, 표 스타일 및 문서 구성 - 머리글/바닥글/페이지 번호가 있으면 확인 - 정확한 재현이 어려운 요소는 한계로 명시 [2. 생성할 스킬] - 위치: .agents/skills/word-report-generator/ - 필수: SKILL.md (이름, 설명, 사용 조건, 실행 절차) - 참고: templates/report_template.docx (원본의 복사본 또는 정리한 템플릿) - 실행 코드: scripts/generate_docx.py - 코드·문서 구조는 가능한 한 단순하게 만들 것 [3. 기능] - report_final.md를 입력으로 받을 것 - Markdown 제목은 Word 제목 스타일에 연결할 것 - 문단과 단순 표를 Word 문서에 반영할 것 - 샘플에 있는 기본 스타일을 최대한 유지할 것 - 원본 DOCX와 MD는 수정·삭제하지 말 것 - 결과는 report_completed.docx로 저장할 것 - Python 패키지는 실행 전에 확인하고 설치 전 승인받을 것 [4. 검사] - SKILL.md가 올바른 위치에 존재하는지 확인 - 필요한 실행 방법을 알려 주고 스킬 인식을 점검 - DOCX가 실제로 열리고 제목·본문·표가 들어 있는지 확인 - 원본과 서식이 다른 부분을 보고 - 실패한 단계가 있으면 원인과 복구 방법을 제시 먼저 계획과 필요한 파일 조작을 요약해 보여 준 다음 실행해 줘.

AI가 `SKILL.md`와 Python 변환 스크립트를 독립 패키지로 자동 구성합니다.

[프롬프트 9] 생성 스킬 실행 및 완성본 DOCX 검수 (P9) DOCX 생성
현재 프로젝트의 word-report-generator 스킬을 사용해 줘. report_final.md를 입력하고, 제공된 Word 샘플에서 추출한 템플릿 스타일을 적용하여 report_completed.docx를 만들어 줘. 원본 파일은 수정하지 말고, 문서 생성 후 아래를 확인해 줘: 1. 제목과 소제목 구조 2. 본문 문단 수 및 내용 누락 3. 표가 있다면 표 구조 4. 서식과 글꼴 5. Word에서 편집 가능한 DOCX인지 실패 항목은 명시적으로 알려 줘.

웹 검색 ➔ 3대 교정을 거친 report_final.md가 내가 만든 스킬을 통해 편집 가능한 정식 Word(report_completed.docx)로 최종 완성됩니다.

  • Word 서식 & 표 잘림 방지: 직접 등록한 스킬로 생성된 report_completed.docx를 Word에서 열었을 때 제목 1·2 스타일이 유지되고 표가 페이지 밖으로 잘리지 않았는가?
  • 보안 및 개인정보 보호: 학번, 전화번호, 비공개 연구 데이터 등 민감한 개인정보가 프롬프트나 외부 도구에 불필요하게 노출되지 않았는가?
  • 비상 PDF 백업 & 사본 준비: 수신자 PC 환경(Word 버전 차이, 폰트 미설치 등)에 따라 서식이 틀어지지 않도록 고정된 PDF 변환본과 클라우드 백업을 준비했는가?

7. 자주 발생하는 문제 & 현장 트러블슈팅 FAQ

실습 중 발생하기 쉬운 환경 오류, 스킬 인식 문제, 서식 깨짐 대처법을 확인하세요.

Q1. Antigravity CLI에서 새로 등록한 스킬을 인식하지 못합니다.
스킬 폴더가 정확히 프로젝트 루트의 .agents/skills/<스킬이름>/ 위치에 있는지 확인하세요. 또한 SKILL.md 상단에 필수 YAML 프론트매터(name, description)가 올바르게 작성되어 있는지 점검하고, CLI 창에서 /skills reload 명령을 실행하거나 새 대화 창을 열어 다시 시도하세요.
Q2. 한글(HWP) 문서를 Markdown으로 변환할 때 내용이 깨지거나 오류가 발생하면 어떻게 하나요?
HWP 파일이 구형 바이너리(한글 97 등)이거나 배포용 보안 문서(암호화)인 경우 텍스트 추출이 제한될 수 있습니다. 실습에서는 표준 HWP 5.0 형식 문서를 사용하며, Antigravity CLI 환경에서 자연어로 변환을 요청하면 에이전트가 최적의 파이썬 도구(pyhwp 등)를 통해 source_hwp.md로 즉시 추출합니다. 필요 시 강사가 준비한 예비 source_hwp.md를 활용할 수 있습니다.
Q3. 한국어 교정 스킬을 실행했더니 원래 문장의 핵심 주장이나 숫자가 바뀌었습니다.
스킬이 추천한 수정안이 항상 100% 정답은 아닙니다. 교정 스킬이 과도하게 문맥을 단축하거나 수치를 누락할 경우, 프롬프트에 명시된 대로 원래 의미와 출처를 보존하는 범위 내에서만 수정안을 채택하고 변경된 문장은 원문과 대조하여 복원해야 합니다.
Q4. Word 스킬 생성 시 복잡한 표나 도형 서식이 그대로 복제되지 않습니다.
python-docx 등 오픈소스 기반 자동화 라이브러리는 글꼴, 크기, 문단 정렬, 표준 표 스타일 등 기본 서식은 정밀하게 제어할 수 있으나, Word 전용 3D 도형, 자유형 텍스트 상자, 복잡하게 셀이 병합된 표의 완벽한 복제에는 기술적 한계가 있습니다. 따라서 실습용 샘플 DOCX는 스타일이 명확하고 구조가 단순한 문서를 권장합니다.
Q5. Google Docs 메뉴에 '도구 > 문서 번역' 메뉴가 보이지 않습니다.
PDF 파일 뷰어 상태이거나 Office 호환성 모드로 열려 있는 경우 문서 번역 메뉴가 비활성화됩니다. 반드시 Google Drive에서 PDF 파일을 마우스 우클릭한 후 연결 앱 > Google 문서를 선택하여 정식 편집 가능한 Google 문서 형태로 완전히 변환한 뒤 상단 메뉴를 확인하세요.
Q6. Antigravity CLI 환경에서 로컬 파일 외에 인터넷 실시간 검색을 통해 Word 문서를 바로 만들 수도 있나요?
네, 100% 가능합니다. Antigravity CLI는 인터넷 실시간 검색 도구와 로컬 Python 환경을 함께 보유하고 있어, 대화창에서 텍스트를 수동으로 복사·붙여넣기할 필요 없이 "자료 웹 검색 ➔ 출처 및 사실 검증 ➔ 표/서식 스타일링 ➔ 로컬 Word(.docx) 파일 직접 생성 및 저장"의 전 과정을 단 한 번의 자연어 지시로 완료할 수 있습니다. Case Study 02에서 직접 만든 커스텀 Word 스킬과 연계하면 학교/기업 양식 그대로 자동 생성할 수도 있습니다.
